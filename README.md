# Система учёта заказов интернет-магазина

Итоговая аттестация по Python (2 курс).

Прототип промышленной системы учёта заказов, клиентов и товаров с графическим интерфейсом, **базой данных Excel** и анализом данных.

## Возможности

- Регистрация клиентов с валидацией email и телефона (регулярные выражения)
- Добавление товаров и создание заказов
- Просмотр, фильтрация и сортировка (собственная реализация пузырьковой сортировки)
- Импорт / экспорт в CSV и JSON
- Анализ данных: топ клиентов, динамика заказов, топ товаров, продажи по городам
- Визуализация (matplotlib, seaborn) и граф связей клиентов (networkx)
- **Хранение данных в Excel файле (shop.xlsx)** с листами для товаров, клиентов, заказов и позиций
- ООП: инкапсуляция, наследование, полиморфизм
- Unit-тесты (unittest)
- Обработка ошибок (try/except)

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd order_management_system
```

### 2. Виртуальное окружение (рекомендуется)

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

> **Примечание:** для tkinter на Linux может потребоваться пакет `python3-tk`:
> ```bash
> sudo apt install python3-tk
> ```

### 4. Запуск

```bash
python main.py
```

При первом запуске база данных создаётся автоматически в `data/shop.xlsx` с листами:
- **products** — товары (id, name, price, category, stock)
- **clients** — клиенты (id, name, email, phone, city)
- **orders** — заказы (id, client_id, order_date, status)
- **order_items** — позиции заказов (id, order_id, product_id, quantity, price)

Через меню **Данные → Загрузить демо-данные** можно заполнить систему тестовыми клиентами, товарами и заказами.

## Краткое описание модулей

| Модуль | Описание |
|--------|----------|
| `models.py` | Классы данных. `BaseEntity` — базовый класс (наследование). Валидация email/телефона через regex. Собственная сортировка и рекурсивный подсчёт суммы. |
| `db.py` | **Excel (pandas + openpyxl)**: CRUD для товаров, клиентов, заказов. Экспорт/импорт CSV и JSON. Демо-данные. Автоматическое управление листами. |
| `gui.py` | Интерфейс на tkinter: вкладки «Клиенты», «Товары», «Заказы», «Анализ». Формы, списки, фильтры, меню. |
| `analysis.py` | pandas + matplotlib/seaborn + networkx. Топ клиентов, динамика, топ товаров, pie-chart по городам, граф связей. |
| `main.py` | Запуск приложения с инициализацией Excel БД. |

## Тестирование

```bash
python -m unittest tests.test_models -v
python -m unittest tests.test_analysis -v

# или все сразу
python -m unittest discover tests -v
```

## Примеры использования GUI

1. **Добавить клиента** — вкладка «Клиенты», заполнить ФИО, email, телефон, город → «Добавить».
2. **Добавить товар** — вкладка «Товары».
3. **Создать заказ** — вкладка «Заказы»: выбрать клиента, добавить позиции, нажать «Создать заказ».
4. **Анализ** — меню «Анализ → Построить все графики» или вкладка «Анализ».
5. **Экспорт** — меню «Файл» для сохранения в CSV/JSON.

## Скриншоты

После запуска и загрузки демо-данных:

**Excel файл `data/shop.xlsx`:**
- Лист `products` — таблица товаров с автоинкрементом ID
- Лист `clients` — таблица клиентов
- Лист `orders` — таблица заказов
- Лист `order_items` — позиции заказов

**Графики** (сохраняются в папку `data/`):
- `top_clients.png` — топ клиентов
- `orders_dynamics.png` — динамика заказов
- `top_products.png` — топ товаров
- `sales_by_city.png` — продажи по городам
- `client_graph_city.png` / `client_graph_products.png` — графы связей

## Технологии

- Python 3.10+
- tkinter

✅ **Портативность**: единый файл .xlsx с лёгкостью копируется и отправляется  
✅ **Интеграция**: легко экспортировать/импортировать из других систем  
✅ **Читаемость**: данные структурированы в понятных листах  
✅ **Масштабируемость**: pandas обрабатывает большие объёмы данных эффективно
