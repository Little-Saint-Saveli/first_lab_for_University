# Изменения: SQLite → Excel

## Краткий обзор

Приложение перепроектировано для использования **Excel (`.xlsx`)** вместо SQLite как основного хранилища данных.

---

## 📋 Детальные изменения

### 1. **db.py** — Полная переработка

#### Что изменилось:
- ❌ Удалено: `sqlite3.connect()`, SQL запросы, таблицы БД
- ✅ Добавлено: `pandas` для работы с DataFrame, `openpyxl` для Excel
- ✅ Структура: Каждая таблица → отдельный лист в Excel файле

#### Листы в Excel (`data/shop.xlsx`):
| Лист | Столбцы | Описание |
|------|---------|---------|
| `products` | id, name, price, category, stock | Товары |
| `clients` | id, name, email, phone, city | Клиенты |
| `orders` | id, client_id, order_date, status | Заказы |
| `order_items` | id, order_id, product_id, quantity, price | Позиции заказов |

#### Основные методы (сигнатура та же):
```python
# CRUD операции — сигнатура не изменилась
db.add_product(product) → int
db.get_product(product_id) → Optional[Product]
db.get_all_products() → List[Product]
db.update_product(product) → None
db.delete_product(product_id) → bool

# Аналогично для clients и orders
db.add_client(client) → int
db.add_order(order) → int
# ...
```

#### Ключевые функции:
- `_read_sheet(sheet_name)` — чтение листа в DataFrame
- `_write_sheet(sheet_name, df)` — сохранение листа
- `_get_next_id(sheet_name)` — автоинкремент ID (вычисляется как `max(id) + 1`)
- Экспорт/импорт CSV и JSON — **работают как раньше**

## 🔄 Как это работает

### Инициализация БД
```
1. При запуске main.py:
   - Database(db_path="data/shop.xlsx") → проверяет наличие файла
   - Если файла нет → _init_db() создаёт пустой Excel с 4 листами
   - Если файл есть → используется существующая БД

2. Демо-данные:
   - db.seed_demo_data() заполняет листы через pandas
```

### Добавление товара
```python
product = Product("Ноутбук", 54990.0, "Электроника", 15)
product_id = db.add_product(product)

# Внутри:
# 1. Читаем лист "products" в DataFrame
# 2. Вычисляем next_id = max(id) + 1
# 3. Добавляем новую строку в DataFrame
# 4. Перезаписываем все листы обратно в Excel
```

### Получение всех заказов
```python
orders = db.get_all_orders()

# Внутри:
# 1. Читаем лист "orders" → получаем DataFrame
# 2. Для каждой строки: get_order(order_id)
# 3. Каждый заказ восстанавливается с товарами из "order_items"
# 4. Возвращаем список Order объектов
```

## ⚠️ Важные замечания

### Параллелизм (многопользовательский доступ)
- ❌ **Excel не поддерживает** одновременное редактирование несколькими процессами
- ✅ SQLite был немного лучше, но всё равно требует обработки блокировок
- **Решение**: Для production используйте PostgreSQL/MySQL

### Производительность
- Для **< 100K записей**: Excel + pandas работает отлично
- Для **> 1M записей**: лучше использовать полноценную БД

### Макросы Excel
- Файл **не содержит** макросов
- Можно безопасно открыть в любом приложении

## 📝 Примечания для разработчика

### Если нужно вернуться на SQLite:

Класс `Database` достаточно обобщен, чтобы его можно было переделать обратно, заменив только:

- Логику получения данных на `fetchone()` / `fetchall()`

Весь остальной код (gui.py, models.py, analysis.py) останется **неизменным**.
